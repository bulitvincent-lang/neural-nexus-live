# Connecteur navigateur Neural Orb

Ce petit module fait vivre votre sphère pendant que vous utilisez ChatGPT, Claude,
Gemini ou Copilot dans votre navigateur.

## Installation (une seule fois)

1. Téléchargez le fichier `neural-orb-connector.zip` puis décompressez-le.
2. Dans votre navigateur, ouvrez la page des modules (Chrome / Edge : menu ▸ Extensions).
3. Activez le mode développeur, cliquez sur « Charger le dossier décompressé » et
   choisissez le dossier obtenu à l'étape 1.

C'est fini. La sphère affiche « Connecté » dès que vous posez une question à votre IA.

## Vie privée

Le connecteur ne lit jamais vos messages, les réponses, vos fichiers ou vos
conversations. Il mesure uniquement le rythme de l'activité (début, en cours,
terminé) et l'envoie à l'application installée sur votre ordinateur. Rien ne
part sur Internet.
